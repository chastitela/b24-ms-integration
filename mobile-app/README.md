# Mobile Confectionery App

This is a simple React Native app for selling confectionery products. It shows a list of items and lets the user add them to the cart.

## Running the App

1. Install dependencies:
   ```bash
   cd mobile-app
   npm install
   ```
2. Start the development server:
   ```bash
   npm start
   ```
3. Use the Expo client to run the app on a mobile device or emulator.
